# ทดสอบท่อจอรับคืนสินค้า — รันในเครื่อง ไม่ต้อง deploy

```bash
node scripts/test-returns/go.mjs
```

**ทำไมต้องมี**: `netlify/lib/core-returns.mjs` แตะบัญชีสต็อกจริง ความผิดพลาดที่นี่
ไม่ล้มระบบ แต่ทำให้ **ตัวเลขสต็อกเพี้ยนเงียบ ๆ** ซึ่งไม่มีตัวตรวจไหนจับได้ย้อนหลัง
D1 คือ SQLite ⇒ เอา SQL ชุดเดียวกันมารันกับ `sqlite3` ในเครื่องได้ตรง ๆ

**วิธีทำงาน**: `go.mjs` คัดลอกไลบรารีจริงแล้วสลับ import สามตัว
(`@netlify/blobs` · `coredb` · `attendance`) ไปที่ `shim.mjs` — **ไม่แก้ไฟล์จริง**

⚠️ **ก่อนเชื่อผลเขียว ให้ป้อนของเสียเข้าไปดูว่ามันแดงจริงไหม**
เคยเจอมาแล้วในชุดนี้เอง: ข้อ ⑩ (SKU ซ้ำ) เขียนไว้ผิดจนผ่านเขียวทั้งที่ถอด
ตัวรวมบรรทัดออกจากโค้ดจริงแล้ว — เพราะทดสอบกับใบขายที่มีใบคืนค้างอยู่
โค้ดจึงคืน "ใบเดิม" แล้วบรรทัดที่ต้องทดสอบไม่เคยถูกเรียก
พิสูจน์แล้วว่าจับได้จริง 3 กรณี: ตัดแถว `return_in` ของของเสีย · ถอดตัวรวม SKU ซ้ำ ·
ถอดด่านบังคับรูป
