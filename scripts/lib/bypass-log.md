# บันทึกการข้ามด่าน push — **ช่องยกเว้นต้องมีร่องรอย**

🔑 **เหตุที่ไฟล์นี้มีอยู่** (14 ต.ค. 2569 · เกณฑ์สามข้อของคุณส้ม)
ส่องช่องยกเว้นทุกช่องในรีโปนี้แล้วพบว่า `SKIP_PREPUSH=1` กับ `ALLOW_FAST_PUSH=1`
เป็น **ช่องที่ทรงอำนาจที่สุด** (ข้ามด่านทั้งอัน / ข้ามกติกาความถี่) แต่:
```
ใครตรวจแทน?      — **ไม่มี**
บังคับอธิบายไหม?  — **ไม่**
โชว์ทุกรอบไหม?    — **ไม่** ⇒ ใช้แล้วไม่เหลือร่องรอยที่ไหนเลย
```
⇒ ⇒ ตามเกณฑ์นั้น **มันไม่ใช่ช่องยกเว้น มันคือรูที่เราเขียนเอกสารกำกับไว้**

✅ สิ่งที่เปลี่ยน: ฮุคจดบรรทัดลงไฟล์นี้ทุกครั้งที่ช่องถูกใช้ **และพิมพ์จำนวนครั้งทุกรอบ**
   (ไม่ใช่พิมพ์ตอนตก — ของที่โชว์ตอนตกคือของที่ไม่มีใครอ่านตอนมันมีประโยชน์)
🚫 **ฮุคไม่บล็อกการใช้ช่อง** — เจตนาคือให้ "ข้าม" เป็นการตัดสินใจที่มีร่องรอย ไม่ใช่สิ่งที่ทำไม่ได้
⚠️ ขอบเขต: ลบไฟล์นี้หรือแก้ฮุค ⇒ ร่องรอยหาย ⇒ **ชั้นสุดท้ายยังเป็นคน** (เขียนไว้ ไม่กลบ)
   แต่ไฟล์นี้อยู่ใน git ⇒ การลบจะเห็นใน diff ซึ่งต่างจากเดิมที่ไม่มีอะไรให้ลบเลย
