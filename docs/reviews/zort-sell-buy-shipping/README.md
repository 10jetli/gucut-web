## สิ่งที่อยู่ในแต่ละหน้า

### 1. สร้างรายการขาย

โครงหลักคือ ประเภทเอกสาร/วันที่/อ้างอิง/ช่องทางขาย/ภาษี/ตัวแทน/ลูกค้า → ตารางสินค้า →
ช่องทางจัดส่ง/หมายเหตุ/ส่วนลด/ค่าส่ง/ยอดสามชั้น → ที่อยู่ผู้รับ → วันส่งและ tracking →
การชำระเงิน → คลังและจังหวะโอนสินค้า ปุ่มท้ายมี **บันทึก**, **บันทึก + สร้างใหม่** และ
**บันทึก + คัดลอกลิงก์** ซึ่งหน้าสร้างซื้อไม่มี

เปิดจริงโดยไม่บันทึกได้ 5 แผง: เลือกผู้ติดต่อ, รายการย้อนหลัง, เลือกสินค้าหลายรายการ,
ชำระเงิน และตัวแทนจำหน่าย DOM ยังชี้ฟังก์ชันภาษีหัก ณ ที่จ่าย, โปรโมชั่น,
วิเคราะห์เอกสารและอัปโหลดไฟล์ด้วย รายชื่อเต็มอยู่ใน evidence JSON

### 2. ใบเสนอราคา

หัวจอมีจำนวน/มูลค่ารวม, นำเข้า Excel, สร้าง, ค้นหา, ค้นหาขั้นสูง, แท็บทั้งหมด/อนุมัติแล้ว,
ตาราง `# · วันที่ · รายการ · ลูกค้า · ช่องทาง · มูลค่า · สถานะ` และ Export to Excel

ฟังก์ชันใน DOM มีแก้วันที่, แก้เลขเอกสาร, ตั้งวันที่เซ็น, พิมพ์ PDF ทีละใบ/หลายใบ,
แก้สถานะ, ส่ง SMS, ลบ, import และเพิ่ม tag เปิดจริงเฉพาะค้นหาขั้นสูงกับ modal นำเข้า
ใบเสนอราคาใหม่ โดยไม่กดบันทึก

### 3. บริการขนส่ง

หัวจอมีจำนวนรายการ, นำเข้ารายการ Excel, ปุ่มขนส่ง, ค้นหา/ค้นหาขั้นสูง, ตาราง
`รายการ · วันที่ · ชื่อผู้รับ · จำนวนรายการขาย · ชำระเงิน · สถานะ · หมายเลขออเดอร์`
และ Export to Excel

แผงขนส่งที่เปิดจริงมีผู้ส่ง/ผู้รับ, จังหวัด–อำเภอ–ตำบล–รหัสไปรษณีย์, COD,
น้ำหนักและขนาดพัสดุ รองรับ DHL, Shopee Express, Flash Express, Thai Post EMS และ KEX
DOM มีการกำหนดขนาดรวดเดียว, คำนวณ/เลือกผู้ให้บริการ, ใช้ Shipping Point,
ส่ง SMS, เติมพอยท์, sync บัญชี Flash/SPX และ `LogisticsBooking` สำหรับยืนยันเรียกขนส่ง
ซึ่งไม่ได้กด

### 4. รับคืนสินค้าจากลูกค้า

ZORT ใช้ `/Buy/list?sttype=1` แต่เมนูอยู่ใต้ **รายการขาย** หัวตารางคือ
`# · วันที่ · รายการ · อ้างอิง · ลูกค้า · มูลค่า · สถานะ · ชำระเงิน`
มีนำเข้า Excel, สร้าง, ค้นหา/ค้นหาขั้นสูง และ Export

ค้นหาขั้นสูงที่เปิดจริงมีเลขรายการ, ช่วงมูลค่า, อ้างอิง, ผู้สร้าง, คลัง, สินค้า,
Serial no, ลูกค้า/โทรศัพท์/อีเมล, สถานะเอกสาร, สถานะชำระ, วันเอกสาร,
วันชำระ และวันโอนสินค้า modal นำเข้าชื่อ **นำเข้ารายการรับคืนใหม่**

DOM ใช้ชุดคำสั่งเดียวกับรายการซื้อหลายตัว เช่นแก้วัน/เลขเอกสาร, พิมพ์เอกสาร,
พิมพ์ใบแปะจดหมาย/กล่อง, หัก ณ ที่จ่าย, ยืนยันชำระ, อนุมัติรายการ และ tag

### 5 และ 8. แพ็คสินค้า / รับสินค้า

เป็น wizard เต็มหน้าสามขั้นที่ต่างกันตาม `type`:

- `type=2`: กรอกหมายเลขรายการ → จัดการแพ็คสินค้า → แพ็คสำเร็จ
- `type=1`: กรอกหมายเลขรายการ → จัดการรับสินค้า → รับสำเร็จ

ทั้งคู่รับ **หมายเลขรายการหรือ Tracking No.** และเขียนเงื่อนไขว่าเอกสารต้องอยู่สถานะ
รอโอนหรือรอบางส่วน DOM ใช้ฟังก์ชัน `Submit`; ไม่ส่งค่าและไม่กดไปขั้นสอง

### 6. สร้างรายการซื้อ

ผังเกือบสมมาตรกับสร้างขาย: ประเภท/วันที่/อ้างอิง/ภาษี/ผู้ติดต่อ → สินค้า → ขนส่ง →
หมายเหตุ/ส่วนลด/ค่าส่งที่ถูกเก็บจากผู้ติดต่อ/ยอดสามชั้น → วันส่งและ tracking → ชำระเงิน →
คลังและเลือก **รอโอนสินค้า** หรือ **โอนทันทีเข้าคลังสินค้า** ปุ่มท้ายมีบันทึกและ
บันทึก + สร้างใหม่

เปิดจริงได้ 4 แผง: ผู้ติดต่อ, รายการย้อนหลัง, สินค้าหลายรายการ และชำระเงิน
DOM มีหัก ณ ที่จ่าย, วิเคราะห์เอกสารและอัปโหลดไฟล์เช่นหน้าสร้างขาย

### 7. รายการซื้อ

หัวจอมีจำนวน/มูลค่ารวมและลิงก์ตรวจนับสินค้าเข้า, นำเข้า Excel, สร้าง,
**สร้างอย่างง่าย**, ค้นหา/ค้นหาขั้นสูง, แท็บทั้งหมด/รอโอน/รอชำระ/สำเร็จ,
ตาราง `# · วันที่ · รายการ · ผู้ติดต่อ · มูลค่า · สถานะ · ชำระเงิน` และ Export

ค้นหาขั้นสูงใช้ชุดช่องใกล้กับหน้ารับคืน แต่เปลี่ยนลูกค้าเป็นผู้ติดต่อ เปิด modal
**นำเข้ารายการซื้อใหม่** และ **สร้างอย่างง่าย** ได้จริงโดยไม่บันทึก
DOM มีพิมพ์เอกสาร/ใบแปะกล่อง, เปลี่ยนวันและเลขเอกสาร, หัก ณ ที่จ่าย,
ชำระเงิน, อนุมัติ และ tag ทั้งแบบใบเดียว/หลายใบ

## จุดที่ควรใช้เป็นเกณฑ์เทียบจอเรา

1. ห้ามยุบ “รับคืนลูกค้า” กับ “คืนให้ผู้ขาย” ตามชื่อ path เพราะ ZORT ไขว้ตระกูล
   `/Buy` และ `/Sell` ด้วย `sttype=1`
2. แพ็คและรับเป็น wizard หน้าตาเดียวกันแต่ข้อความและผลขั้นสุดท้ายคนละความหมาย
3. หน้ารายการไม่ได้มีแค่ตาราง: import, advanced search, export, print, tag,
   เปลี่ยนวัน/เลขเอกสาร และคำสั่งหลายใบเป็นส่วนของผังจริง
4. บริการขนส่งรวมทั้งการสร้างงานส่ง, ที่อยู่, COD, มิติพัสดุ, ผู้ให้บริการ,
   Shipping Point และการเรียกขนส่ง จอที่มีแค่ตารางจึงยังไม่เท่าหน้านี้
5. สร้างขายมีช่องทางขาย, ตัวแทน, ที่อยู่ผู้รับ และคัดลอกลิงก์เพิ่มจากสร้างซื้อ
   ส่วนสร้างซื้อใช้คำว่าโอนทันที **เข้า** คลัง; สร้างขายใช้โอนทันที **ออก** จากคลัง
